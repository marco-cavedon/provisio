# 0012 — React for the frontend

- **Status:** Accepted
- **Date:** 2026-10-06

## Context and problem statement

The author's primary frontend experience is Angular. React is more widespread among international product companies.

## Decision outcome

React, as a deliberate choice to broaden the author's skill set, accepting a learning cost.
The UI scope is kept minimal: proposal review, approval and process status.

## Consequences

### Positive

- Broader, more transferable frontend experience.

### Negative

- Slower initial delivery on the frontend.
